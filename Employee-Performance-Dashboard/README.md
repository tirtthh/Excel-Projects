# Employee Performance Analysis Dashboard (Excel)

## 📊 Project Overview
Analyzed employee performance, attendance, and productivity using Excel to generate insights for workforce optimization.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- VLOOKUP / XLOOKUP
- Charts & Slicers

## 📈 Key Insights
- Identified high-performing employees
- Analyzed attendance trends affecting productivity
- Helped improve workforce efficiency
