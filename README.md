# Excel Data Analysis Dashboard Projects

This repository contains **interactive Excel dashboards** created for data analysis and visualization.
The projects demonstrate skills in **data cleaning, pivot tables, dashboard design, and business insights using Microsoft Excel**.

---

# Projects Included

## 1. Customer Support Dashboard

This dashboard analyzes customer support ticket performance.

### Key Metrics

* Total Tickets
* Open Tickets
* Resolved Tickets
* Closed Tickets
* Critical Priority Tickets

### Analysis Included

* Ticket Status Distribution
* Ticket Priority Breakdown
* Ticket Type Analysis
* Top 10 Products with Issues
* Customer Gender Distribution
* Quarterly Ticket Trends

### Filters

Interactive slicers allow filtering by:

* Customer Gender
* Ticket Type
* Ticket Priority
* Ticket Status

### Dashboard Preview

![Customer Support Dashboard](customer_support_dashboard.png)
